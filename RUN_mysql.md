### MySQL Docker Environment

Start MySQL:
```bash
bash docker/start_mysql.sh
```

Open a MySQL shell:
```bash
bash docker/run_mysql.sh
```

Stop MySQL:
```bash
bash docker/stop_mysql.sh
```

Reset MySQL data:
```bash
bash docker/reset_mysql.sh
```

Connection defaults:
- host: `localhost`
- port: `3306`
- database: `workload`
- user: `root`
- password: `mysql`
- root password: `mysql`
