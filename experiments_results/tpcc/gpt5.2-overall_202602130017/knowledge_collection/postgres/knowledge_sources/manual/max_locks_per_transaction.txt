**SENTENCE:** `max_locks_per_transaction` sets the average number of distinct objects (e.g., tables) each transaction can lock by sizing the shared lock table to `max_locks_per_transaction × (max_connections + max_prepared_transactions)` entries (default **64**), so increase it if single transactions touch many tables; it applies at server start and standby should be set **≥** primary (it does **not** limit rows locked).
