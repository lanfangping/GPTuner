**SENTENCE:** `autovacuum_analyze_scale_factor` sets the extra fraction of a table’s row count added to `autovacuum_analyze_threshold` to decide when AUTOVACUUM runs ANALYZE (default **0.1 = 10%**; e.g., on a **100,000-row** table it adds **10,000**), configurable only in `postgresql.conf`/server command line but overridable per table via storage parameters.
