**SENTENCE:** `wal_sync_method` selects **which OS sync mechanism** PostgreSQL uses to **force WAL writes to durable storage at each commit** (options: `open_datasync`, `fdatasync`, `fsync`, `fsync_writethrough`, `open_sync`); it matters only when `fsync=on`, defaults to the **first supported method** (typically `fdatasync` on **Linux/FreeBSD**), and is set only in `postgresql.conf` or via the server command line.
