When `full_page_writes` is **on** (default), PostgreSQL logs a **full 8 KB page image** to WAL the **first time each page is modified after every checkpoint**, increasing WAL volume but preventing **partial-page-write corruption** after crashes; turning it **off** can reduce WAL writes but risks **unrecoverable or silent data corruption**, and it can only be set in `postgresql.conf` or on the server command line.
