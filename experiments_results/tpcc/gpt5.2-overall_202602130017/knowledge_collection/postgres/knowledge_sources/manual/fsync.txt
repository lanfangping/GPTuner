**SENTENCE:** `fsync` (on/off; default **on**) forces PostgreSQL to issue **fsync()-style disk flushes** so data is durable after a crash, but setting it **off** may improve performance at the cost of **possible unrecoverable corruption on any power loss/crash**, so only disable it for throwaway/rebuildable clusters (and if re-enabling, run **initdb --sync-only** or an OS **sync/reboot** to flush dirty buffers).
