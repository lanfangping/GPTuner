**wal_buffers** sets how much shared memory PostgreSQL uses to buffer unwritten WAL, defaulting to **-1 = shared_buffers/32 (~3%)** with bounds of **64 kB minimum** and **one WAL segment maximum (typically 16 MB)**; values **<32 kB become 32 kB**, unitless values are in **WAL blocks (typically 8 kB each)**, it’s **set only at server start**, and increasing it beyond **a few MB** rarely helps because WAL buffers flush on every commit.
