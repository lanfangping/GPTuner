**shared_preload_libraries**: A **comma-separated list of shared library names** that PostgreSQL **preloads once at server start** (required for libraries needing postmaster-start actions like shared memory/LWLocks/background workers); it is **postmaster-start only** (changing it requires a **server restart**), and if **any listed library is missing the server will not start**, while preloading can reduce first-use load time at the cost of slightly longer per-process startup (and on **Windows** each process re-loads them).
