**SENTENCE:** `old_snapshot_threshold` sets the maximum age a query snapshot can be before PostgreSQL may vacuum away dead rows and, if that snapshot later reads a page changed since it was taken, raise “snapshot too old”; it’s in **minutes by default**, **-1 (default) disables it (infinite age)**, typical production values are **hours to a few days** (even though up to **60d** is allowed), and it **can only be set at server start**.
