**SENTENCE:** `autovacuum_vacuum_scale_factor` sets the fraction of a table’s row count added to `autovacuum_vacuum_threshold` to decide when autovacuum VACUUM runs (default **0.2 = 20%**; e.g., a **100,000-row** table adds **20,000** to the threshold), and it’s set in `postgresql.conf`/command line but can be overridden per table via storage parameters.
