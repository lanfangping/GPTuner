Set `jit_inline_above_cost` to the **typical total cost threshold** (in planner cost units) above which you want PostgreSQL to allow JIT inlining—e.g., start with the default **500,000**, **lower it (≈50,000–200,000)** to inline more aggressively for expensive, CPU-bound queries, or **raise it (≈1,000,000–5,000,000)** to reduce compilation/inlining overhead if queries are shorter or latency-sensitive.
