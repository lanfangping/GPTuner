Set `cpu_index_tuple_cost` to approximate the CPU time (in the same cost units as `seq_page_cost`/`random_page_cost`) to process one index tuple, typically **0.005** (PostgreSQL default), and adjust within about **0.001–0.02** based on your hardware/workload—**lower it (e.g., 0.002–0.004)** if CPU is fast and index processing is cheap so the planner favors index scans, or **raise it (e.g., 0.008–0.02)** if CPU is a bottleneck or index scans are turning out more expensive than the planner predicts.
