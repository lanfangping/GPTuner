Set `checkpoint_completion_target` close to **0.9** (typical safe range **0.7–0.9**, sometimes up to **0.95**) so PostgreSQL spreads checkpoint writes over ~**90%** of the checkpoint interval; e.g., with `checkpoint_timeout = 15min`, targeting **0.9** aims to finish writes by about **13.5 min**, reducing I/O spikes (lower it like **0.5–0.7** if you need faster completion because checkpoints are being missed).
