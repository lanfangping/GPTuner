Set `autovacuum_analyze_threshold` to a low absolute floor so small/medium tables still get analyzed (commonly **50–500 rows**, default **50**), and rely on `autovacuum_analyze_scale_factor` for large tables—e.g., if you want an analyze roughly every **10,000** row changes on a table, set `threshold ≈ 500` and `scale_factor ≈ (10,000 − 500) / table_rows` (so for a **1,000,000**‑row table, `scale_factor ≈ 0.0095`).
