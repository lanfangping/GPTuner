Set `autovacuum_vacuum_scale_factor` to the fraction of a table’s rows that can change before an autovacuum is triggered (trigger ≈ `autovacuum_vacuum_threshold + autovacuum_vacuum_scale_factor * reltuples`), so for large/high‑churn tables lower it from the default `0.2` to about `0.01–0.05` (e.g., a 10M‑row table with threshold 50 triggers at ~2,000,050 changes with `0.2`, but ~100,050 with `0.01`), while for small/rarely updated tables you can keep `0.2` or higher.
