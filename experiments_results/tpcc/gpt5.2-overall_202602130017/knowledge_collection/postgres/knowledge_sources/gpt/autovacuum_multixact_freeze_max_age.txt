Set `autovacuum_multixact_freeze_max_age` to a value safely below `2,000,000,000` (the multixact wraparound limit) so autovacuum freezes multixacts early enough to prevent wraparound; in practice keep it near the default `400,000,000`, raise it (e.g., `600,000,000–1,000,000,000`) only if you have plenty of maintenance capacity and want fewer aggressive vacuums, and lower it (e.g., `200,000,000–300,000,000`) if you see “multiXact age” climbing fast or get close to wraparound warnings.
