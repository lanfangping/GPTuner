Set `autovacuum_vacuum_threshold` to a base number of dead tuples that should trigger vacuum, typically **~50–1000** (default **50**), and tune it together with `autovacuum_vacuum_scale_factor` so that vacuum starts around **0.1–1% of table size** (e.g., for a **10M-row** table, use scale factor **0.001** and keep threshold **50–200**, yielding a trigger at **≈10,050–10,200** dead tuples).
