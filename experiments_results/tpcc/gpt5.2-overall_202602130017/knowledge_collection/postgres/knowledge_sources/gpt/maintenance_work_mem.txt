Set `maintenance_work_mem` to the amount of RAM you can safely dedicate **per maintenance operation** (VACUUM, CREATE/REINDEX INDEX, ALTER TABLE … ADD FOREIGN KEY), typically **256MB–1GB per concurrent job** (e.g., start at **512MB**), and ensure **(maintenance_work_mem × max concurrent maintenance tasks)** stays well below available memory (e.g., on a **32GB** server with up to **4** parallel index builds, use about **512MB–1GB** → **2–4GB total**, not 16GB+).
