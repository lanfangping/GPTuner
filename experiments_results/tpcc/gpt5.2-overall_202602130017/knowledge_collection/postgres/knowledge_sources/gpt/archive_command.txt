Set `archive_command` to a shell command that reliably copies each completed WAL file from `%p` to your archive destination `%f` (and returns exit code 0 only on success), typically like `test ! -f /archive/%f && cp %p /archive/%f` for local archiving, or `rsync -a %p archivehost:/archive/%f` / `barman-wal-archive … %p %f` for remote, and size the archive target to hold at least **hours–days** of WAL (roughly **WAL_rate_MB_per_hour × retention_hours**, noting WAL segments are **16 MB** by default).
