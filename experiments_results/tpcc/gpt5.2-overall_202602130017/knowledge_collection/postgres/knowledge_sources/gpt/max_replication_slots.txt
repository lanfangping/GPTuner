Set `max_replication_slots` to at least the maximum number of concurrent slot users you need (one per logical replication subscription, physical replication slot, or CDC tool) plus a small cushion—e.g., if you have 2 physical standbys and 3 logical subscriptions, set it to ≥5 (often 6–8 to allow maintenance/failover), and remember each active slot consumes WAL retention so don’t set it arbitrarily high.
