Set `local_preload_libraries` to a comma‑separated list of only the libraries you need loaded for *this database*, starting with none (`''`), and add extensions one by one (e.g., `local_preload_libraries='auto_explain,pg_stat_statements'`); as a rule of thumb keep it small—typically **0–3 libraries**, since each one adds startup/memory overhead for sessions that connect to that database.
