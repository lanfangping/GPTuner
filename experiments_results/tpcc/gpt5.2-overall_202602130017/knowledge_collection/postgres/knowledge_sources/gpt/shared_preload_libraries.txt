Set `shared_preload_libraries` to only the extensions that must hook into PostgreSQL at startup (e.g., start with `pg_stat_statements` alone, then add others like `auto_explain`, `timescaledb`, etc. as needed), keeping the list typically at **0–3 libraries** (e.g., `shared_preload_libraries = 'pg_stat_statements'`), because **every additional library increases baseline memory/CPU and requires a server restart**.
