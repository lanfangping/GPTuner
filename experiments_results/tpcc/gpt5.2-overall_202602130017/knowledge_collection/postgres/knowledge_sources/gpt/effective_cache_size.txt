Set `effective_cache_size` to your best estimate of **how much data Postgres can keep cached in RAM overall** (Postgres shared buffers + OS page cache, excluding memory needed by the OS/other apps), and in practice start around **50–75% of total system RAM** on a dedicated DB server (e.g., **16 GB RAM → 8–12 GB**, **64 GB → 32–48 GB**) and adjust if the machine isn’t dedicated (lower it by the RAM used elsewhere).
