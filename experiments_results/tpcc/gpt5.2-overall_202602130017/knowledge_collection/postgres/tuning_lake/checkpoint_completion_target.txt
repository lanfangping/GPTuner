{'suggestion': 'Configure `checkpoint_completion_target` in `postgresql.conf` (or via the server command line) to control how aggressively PostgreSQL spreads checkpoint I/O across the time between checkpoints: higher values spread writes over a larger portion of the checkpoint interval to smooth I/O (e.g., with a 5‑minute interval, `0.5` targets ~2.5 minutes and `0.9` targets ~4.5 minutes; default is `0.5`). A common setting—especially on development instances—is around `0.9`, but if you depend on this behavior to feed non-streaming replicas, keep it at a lower percentage.'}
