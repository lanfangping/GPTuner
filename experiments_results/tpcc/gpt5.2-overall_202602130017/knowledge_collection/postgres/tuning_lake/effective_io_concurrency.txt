{'suggestion': 'Tune PostgreSQL `effective_io_concurrency` to control how many disk I/O requests it will try to run in parallel per session during bitmap heap scans. Set it to 1 to effectively disable async I/O (and note it may be disabled on unsupported systems); otherwise choose a value that matches your storage’s useful in-flight I/O capacity—often roughly the number of underlying data drives in a RAID0/RAID1 setup (excluding RAID5 parity), and potentially much higher (up to hundreds) on SSD/NVMe—then increase gradually until latency/throughput stops improving without exceeding what the storage can handle.'}
