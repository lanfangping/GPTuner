{'suggestion': 'Configure `temp_buffers` as a per-session cap for memory used by temporary-table buffers. The default is 8MB (about 1024 8KB blocks). It can only be changed before the session first accesses a temporary table. Memory impact includes roughly 64 bytes of metadata per configured buffer plus 8KB (BLCKSZ) for each buffer actually used. If your workload uses temporary tables heavily and they spill to disk, consider increasing `temp_buffers` (e.g., start around 16–64MB per connection, and raise further if needed), remembering it is per session so total potential RAM use scales with concurrent sessions (`temp_buffers × concurrent sessions`).'}
