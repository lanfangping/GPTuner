{'suggestion': 'Use `autovacuum_vacuum_threshold` to control when autovacuum runs VACUUM by setting the minimum number of updated/deleted (dead) rows that must accumulate before a table is vacuumed. Configure it in `postgresql.conf` or via the server command line, and override it per-table using storage parameters when needed. Tune it together with `autovacuum_vacuum_scale_factor` so vacuum triggers at an appropriate fraction of table size (often around ~0.1–1%); for example, on a ~10M-row table you might use a scale factor of 0.001 with a threshold around 50–200 to trigger at roughly 10,050–10,200 dead tuples.'}
