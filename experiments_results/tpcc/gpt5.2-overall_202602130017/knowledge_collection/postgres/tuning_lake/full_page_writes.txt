{'suggestion': 'Keep PostgreSQL `full_page_writes` set to **on** (the default), especially if you use **WAL archiving or replication** or need strong crash-safety. With it enabled, PostgreSQL writes a **full-page image** to WAL the **first time a page is modified after each checkpoint**, which increases WAL volume (most noticeably with **frequent checkpoints** and write-heavy workloads) but protects against **partial-page-write corruption** after crashes. Disable it (`off`) only in tightly controlled scenarios where you can accept the risk of **unrecoverable or silent data corruption** in exchange for reduced WAL/write volume. Note that `full_page_writes` can be set only in `postgresql.conf` or via the server command line.'}
