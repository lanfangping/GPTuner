{'suggestion': 'Configure PostgreSQL `shared_buffers` to control how much RAM is dedicated to the shared buffer cache (default is ~128MB). Use ~25% of system RAM as a practical starting point; increases are rarely beneficial above ~40% and should be validated with your own benchmarks. Account for whether the server is dedicated or running multiple PostgreSQL instances (each reserves its own memory). Ensure the setting is compatible with OS shared-memory limits (e.g., `shmmax`/`shmall`), and on very large-memory systems consider using huge pages. Note that `shared_buffers` is only changeable at server start.'}
