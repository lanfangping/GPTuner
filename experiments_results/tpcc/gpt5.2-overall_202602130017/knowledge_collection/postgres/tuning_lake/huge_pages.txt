{'suggestion': 'Use `huge_pages` to control whether PostgreSQL requests huge/large pages for its main shared memory: `try` (default) will attempt to use huge pages and fall back if unavailable, `on` will require huge pages (startup fails if they are not available), and `off` will never request them. This setting is supported only on Linux/Windows, and on Linux only when `shared_memory_type=mmap`. Prefer leaving it at `try` unless you explicitly want to require huge pages; only set `on` if you understand the OS configuration requirements and have huge pages properly provisioned.'}
