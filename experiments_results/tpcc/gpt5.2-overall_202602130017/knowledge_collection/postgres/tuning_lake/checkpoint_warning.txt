{'suggestion': 'Use `checkpoint_warning` to generate a server log warning when WAL-fill checkpoints occur less than the configured interval apart, which indicates checkpoint pressure and typically suggests increasing `max_wal_size`. Configure it in `postgresql.conf` (or via the server command line) to a value that is a reasonable fraction of `checkpoint_timeout` (commonly around 30–60s, e.g., `checkpoint_warning = 30`). Note that no warning is emitted if `checkpoint_timeout` is set lower than `checkpoint_warning`.'}
