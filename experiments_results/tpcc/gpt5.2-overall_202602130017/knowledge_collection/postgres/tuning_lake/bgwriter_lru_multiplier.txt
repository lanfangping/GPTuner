{'suggestion': 'Tune `bgwriter_lru_multiplier` based on how much cushion you want the background writer to maintain beyond the recent average buffer demand. It multiplies the recent average number of buffers needed per round (e.g., if ~100 new buffers/round and `bgwriter_lru_multiplier=2.0`, it targets ~200 clean buffers by writing dirty ones). `1.0` is roughly just-in-time; higher values add cushion and shift more writing to the background writer, while lower values shift more writing to backends. For most systems, start around `2.0–3.0`; increase (e.g., `4+`) if you observe many buffers being written by backends (indicating the bgwriter can’t keep up), and decrease (e.g., `1.0–2.0`) if the bgwriter is doing excessive work for little benefit. Note that each round’s work is capped by `bgwriter_lru_maxpages`.'}
