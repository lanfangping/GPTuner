{'suggestion': 'Set `maintenance_work_mem` to an appropriate per-operation memory limit for maintenance tasks (e.g., VACUUM, CREATE/REINDEX INDEX, ADD FOREIGN KEY). The default is 64MB (unitless values are in kB). Increasing it can speed up maintenance work, especially on systems with ample RAM and heavy write activity, but size it with concurrency in mind: while only one such task runs per session, autovacuum can allocate up to `autovacuum_max_workers × maintenance_work_mem` (unless controlled by `autovacuum_work_mem`). Also note VACUUM’s dead-tuple collection uses at most 1GB.'}
