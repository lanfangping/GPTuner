A higher value, such as the default of 4GB, makes it more likely to use an index scan over a sequential scan. A good approximation for this setting is: system RAM - (shared_buffers + work_mem * max_connections * 2) * 1.1, but use a lower value if the server is not dedicated exclusively to PostgreSQL. Note that this setting only influences query planning and does not affect the amount of physical RAM used by queries.'}
