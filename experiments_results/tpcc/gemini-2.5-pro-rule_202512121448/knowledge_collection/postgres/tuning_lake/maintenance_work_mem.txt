A common strategy is to set a moderate global value in `postgresql.conf` (e.g., 256MB to 1GB) for general autovacuum use, and temporarily increase it per-session to a much larger value (e.g., 1GB to 8GB+) before running intensive manual operations like `CREATE INDEX`.'}
