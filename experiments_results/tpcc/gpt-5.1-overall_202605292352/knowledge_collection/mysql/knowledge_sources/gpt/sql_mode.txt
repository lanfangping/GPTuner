Set `sql_mode` by listing the desired modes as a comma‑separated string (e.g., `sql_mode='STRICT_TRANS_TABLES,NO_ENGINE_SUBSTITUTION'`), and remember that a *blank* `sql_mode` (i.e., `sql_mode=''`) removes all modes, while MySQL 8.0’s default includes multiple modes such as `ONLY_FULL_GROUP_BY`, `STRICT_TRANS_TABLES`, `NO_ZERO_DATE`, `NO_ZERO_IN_DATE`, `ERROR_FOR_DIVISION_BY_ZERO`, `NO_ENGINE_SUBSTITUTION`, and others (typically 7–10 modes depending on version and distribution).
