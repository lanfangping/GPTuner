{'suggestion': 'Use `default_statistics_target` to control the default per-column statistics detail that `ANALYZE` collects when no column-specific target is set. Keep the default value (100) for general use, and increase it when you need better planner row-estimate accuracy—especially on large tables or on columns with skewed data that cause poor plans—while accounting for the tradeoff that higher values make `ANALYZE` take longer (and increase statistics size roughly proportionally). Typical increases are to ~200 for many medium-sized workloads, ~200–500 for skewed/problem columns, and up to ~1000 only when necessary for a small number of critical columns, preferably by setting a per-column target via `ALTER TABLE ... ALTER COLUMN ... SET STATISTICS` rather than raising the global default.'}
