{'suggestion': 'Configure `temp_buffers` as a per-session cap for memory used by temporary-table buffers. Set it to an amount of RAM you can afford per session (often starting around 64–256MB on a dedicated DB server), and increase it only if you observe temporary-file I/O (e.g., via `temp_files`/`log_temp_files`). Keep in mind the worst-case total RAM impact scales with concurrency (approximately `temp_buffers` × number_of_concurrent_sessions). Note that `temp_buffers` can only be changed before a session’s first use of a temporary table, and additional configured buffers incur ~64B overhead each plus 8kB (BLCKSZ) per buffer when actually used.'}
