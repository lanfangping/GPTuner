{'suggestion': 'Tune PostgreSQL `effective_io_concurrency` (which controls how many disk I/O requests can run in parallel during bitmap heap scans): set it to 0 to disable asynchronous I/O, or set it to a value that matches your storage’s parallel I/O capability—often roughly the number of RAID data disks, and for SSDs potentially in the hundreds. Note the defaults are 1 on systems that support it and 0 otherwise.'}
