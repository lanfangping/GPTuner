Set `effective_cache_size` to an estimate of the *total* memory PostgreSQL can effectively rely on for caching data pages—typically about **50–75% of RAM** after accounting for the OS and other processes (including PostgreSQL’s own `shared_buffers`), e.g., on a **32 GB** server a common starting range is **16–24 GB** (so you might set `effective_cache_size = 24GB` if the machine is mostly dedicated to Postgres).
