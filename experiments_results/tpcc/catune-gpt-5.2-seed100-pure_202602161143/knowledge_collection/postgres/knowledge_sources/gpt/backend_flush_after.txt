Set `backend_flush_after` to a nonzero size only if you want to force periodic writeback during large sequential writes: start with the default `0` (disabled), and if you enable it use a value around **1–2 MB** (e.g., `backend_flush_after = 1MB`), increasing up to **4–8 MB** if you still see long I/O stalls, while avoiding very small values (e.g., **<256 kB**) that can add overhead.
