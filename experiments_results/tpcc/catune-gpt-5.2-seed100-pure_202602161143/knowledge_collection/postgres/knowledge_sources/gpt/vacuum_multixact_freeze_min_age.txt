Set `vacuum_multixact_freeze_min_age` to a moderate fraction of `autovacuum_multixact_freeze_max_age` so autovacuum starts freezing multixacts well before the wraparound emergency—commonly **~10–25%** of the max; for example, if `autovacuum_multixact_freeze_max_age = 400,000,000` (default), use **40,000,000–100,000,000** (and only raise it if freeze-related vacuum work is too frequent, while keeping plenty of headroom before the max).
