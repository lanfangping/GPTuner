Set `bgwriter_lru_maxpages` based on how many buffers the background writer must clean each cycle to keep backends from doing their own writes: start with the default **100**, increase in steps (e.g., **200 → 500 → 1000+**) if `pg_stat_bgwriter.maxwritten_clean` is frequently non‑zero (bgwriter hitting its limit), and decrease (even to **0**) if it stays at/near **0** and you want to reduce background I/O.
