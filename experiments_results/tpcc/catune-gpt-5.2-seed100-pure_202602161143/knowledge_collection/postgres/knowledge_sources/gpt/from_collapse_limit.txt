Set `from_collapse_limit` to about the number of tables/subqueries you’re comfortable letting PostgreSQL freely reorder in the `FROM` list—keep the default **8** for most workloads, raise it (e.g., **12–20**) only if you often run **>8-way joins** and planning time is acceptable, or lower it (e.g., **4–6**) if you have very complex joins where you need to **cap optimizer planning time**.
