Set `bgwriter_lru_multiplier` based on how often backends are forced to write buffers themselves: start at **2.0** (default), raise gradually to **3–5** if you see many `buffers_backend` writes in `pg_stat_bgwriter` (and you have I/O headroom), and lower toward **1.0–2.0** if the background writer is creating unnecessary I/O pressure—typical practical values are **2–4**, and going much above **10** is rarely useful.
