Set `max_parallel_workers` to approximately the total number of CPU cores available to PostgreSQL (e.g., 8 on an 8‑core host, 32 on a 32‑core host), and if you run multiple concurrent parallel queries, size it closer to “cores × expected concurrent parallel queries” but cap it at a practical ceiling (commonly ~2× cores, e.g., 16 for 8 cores or 64 for 32 cores) to avoid CPU contention.
