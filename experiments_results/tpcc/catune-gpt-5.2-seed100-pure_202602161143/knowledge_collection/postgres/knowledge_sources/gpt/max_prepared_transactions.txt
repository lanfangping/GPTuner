Set `max_prepared_transactions` to the **maximum number of concurrent two‑phase (PREPARE TRANSACTION) transactions you expect**, typically **0 if you don’t use 2PC**, otherwise roughly **equal to `max_connections`** (e.g., with `max_connections=200`, set `max_prepared_transactions≈200`; with `max_connections=500`, set it ≈500), because it must be high enough to cover peak prepared transactions but higher values consume additional shared memory.
