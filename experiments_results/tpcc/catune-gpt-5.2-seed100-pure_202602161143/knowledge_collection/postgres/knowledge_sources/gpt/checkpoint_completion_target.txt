Set `checkpoint_completion_target` to control how much of the time between checkpoints PostgreSQL tries to spread checkpoint writes over: start at **0.9** (common default on modern systems), use **0.7–0.8** if you need checkpoints to finish earlier (at the cost of more write burst), and consider **0.95** on fast storage if you want the smoothest write I/O—then verify by ensuring checkpoints typically complete well before the next one (e.g., **<80–90%** of the checkpoint interval in `pg_stat_bgwriter`).
