Set `default_statistics_target` based on how much planner accuracy you need versus ANALYZE/maintenance overhead: keep the default **100** for general use, raise to about **200–500** for tables/columns with skewed distributions or bad row-estimate plans, and only go as high as **1000–10000** (preferably per-column via `ALTER TABLE ... ALTER COLUMN ... SET STATISTICS`) for a few critical columns where misestimates are costly, noting that higher values increase stats size and ANALYZE time roughly proportionally.
