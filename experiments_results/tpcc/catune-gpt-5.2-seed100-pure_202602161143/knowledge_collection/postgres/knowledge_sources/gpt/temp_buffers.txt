Set `temp_buffers` to roughly the amount of RAM you can afford **per session** for temporary tables—**start at 64–256MB** on a dedicated DB server (default is **8MB**), only raise it if you see temp-file I/O (e.g., `temp_files`/`log_temp_files`), and remember the total possible RAM use is about **`temp_buffers` × number_of_concurrent_sessions`** (e.g., **128MB × 50 ≈ 6.4GB** worst case).
