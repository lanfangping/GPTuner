Set `max_worker_processes` to at least the total number of background worker processes you expect to run concurrently—typically **~8–16 on small servers**, and on larger systems **≈ (max_parallel_workers + max_parallel_maintenance_workers + a few for autovacuum/other extensions)**—but **do not exceed the number of CPU cores** (e.g., **16 cores → set ~16–24 if you need parallel query + maintenance + extensions; otherwise ~16**).
