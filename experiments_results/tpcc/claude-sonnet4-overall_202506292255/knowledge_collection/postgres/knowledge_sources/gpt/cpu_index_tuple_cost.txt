The `cpu_index_tuple_cost` parameter in PostgreSQL should typically be set to a value between 0.001 and 0.01 (with default being 0.005), where you should decrease it to around 0.001-0.003 if your system has fast CPUs or SSDs to encourage more index usage, or increase it to 0.007-0.01 on slower systems where index processing is more expensive relative to sequential operations.
