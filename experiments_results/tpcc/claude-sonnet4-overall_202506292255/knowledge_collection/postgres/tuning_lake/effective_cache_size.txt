It should be set to approximately: system RAM - (shared_buffers + work_mem * max_connections * 2) * 1.1, or a lower value if the server is not dedicated exclusively to PostgreSQL. This parameter tells PostgreSQL how much memory is available for caching data across the entire system including both PostgreSQL's buffers and the OS page cache, where higher values favor index scans over sequential scans to help the query planner make better decisions about index usage. Note that this setting does not affect the amount of physical RAM used by queries."}
