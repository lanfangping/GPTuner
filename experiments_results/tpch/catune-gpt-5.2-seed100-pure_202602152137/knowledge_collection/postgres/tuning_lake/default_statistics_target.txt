{'suggestion': 'Use `default_statistics_target` to control the default per-column statistics target that `ANALYZE` collects when no column-specific target is set. Keep the default value **100** for most workloads, and increase it only when you need better planner estimates (e.g., large tables or columns with skewed data and frequent misestimates). Raising the target can improve cardinality estimates but increases `ANALYZE` time and the size of collected statistics roughly proportionally. If only a few columns are problematic, prefer setting a higher per-column target with `ALTER TABLE ... ALTER COLUMN ... SET STATISTICS` rather than raising the global default.'}
