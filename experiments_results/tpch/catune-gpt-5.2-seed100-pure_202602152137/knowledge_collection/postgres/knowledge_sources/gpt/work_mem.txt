Set `work_mem` so that **(concurrent “memory-hungry” operations per session) × (`work_mem`) × (number of active sessions)** fits comfortably in RAM (e.g., with 16 GB RAM and ~4 GB reserved for OS/shared_buffers, leaving ~12 GB: if you expect ~20 active sessions each doing ~2 sorts/hashes at once → ~40 ops, set `work_mem` ≈ 12 GB/40 ≈ **300 MB**, then start lower—often **16–64 MB**—and raise while watching temp-file spills and memory pressure).
