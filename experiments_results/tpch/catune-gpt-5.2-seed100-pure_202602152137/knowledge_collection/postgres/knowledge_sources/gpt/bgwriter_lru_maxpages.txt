Set `bgwriter_lru_maxpages` based on how much background write work you want per wake-up: start with the default `100`, and if you see high `buffers_backend`/`buffers_backend_fsync` or backend write spikes, raise it in steps (e.g., `200 → 500 → 1000`), while if checkpoints are causing most writes (high `buffers_checkpoint`) or you want to cap background I/O, lower it (e.g., `50` or `0` to disable LRU background writes).
