Set `checkpoint_completion_target` to **0.9** as a safe default (it spreads checkpoint I/O across ~90% of the checkpoint interval); if you still see checkpoint-induced write spikes, raise toward **0.95–0.99**, and if you need faster checkpoint completion (at the cost of more bursty I/O) lower to **0.7–0.8**—typical practical range is **0.7–0.99** (default is **0.9** in modern Postgres).
