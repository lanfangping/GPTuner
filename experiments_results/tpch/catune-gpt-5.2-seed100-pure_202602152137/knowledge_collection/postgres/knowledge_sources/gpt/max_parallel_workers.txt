Set `max_parallel_workers` to roughly the total number of CPU cores available to PostgreSQL (e.g., 16 cores → set it around **16**), increasing if you run many concurrent parallel queries and decreasing if parallelism would contend with other workloads—while keeping in mind it only caps the system-wide pool and should align with `max_worker_processes` (which must be **≥ max_parallel_workers**) and typical per-query limits like `max_parallel_workers_per_gather` (often **2–4**).
