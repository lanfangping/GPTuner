Set `default_statistics_target` based on how many columns need good cardinality estimates: keep the default **100** for most workloads, raise to **200–500** for tables/columns with skewed data and frequent misestimates (and consider **1000+** only for a few critical columns via per-column `ALTER TABLE … SET STATISTICS`), because higher values improve planner estimates but increase `ANALYZE` time and `pg_statistic` size roughly proportionally.
