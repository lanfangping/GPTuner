Set `bgwriter_delay` to a low value when you want smoother, more continuous background writes (typical starting point **200ms**, decrease toward **10–50ms** if you’re seeing checkpoint spikes and the system can handle more frequent wakeups) and to a higher value only if you need to reduce bgwriter wakeups/CPU overhead (**500–1000ms**), using `pg_stat_bgwriter` to confirm that `buffers_backend`/`buffers_backend_fsync` stay low and `buffers_checkpoint` doesn’t jump.
