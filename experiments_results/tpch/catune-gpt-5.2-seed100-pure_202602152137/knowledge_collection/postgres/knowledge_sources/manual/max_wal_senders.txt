**SENTENCE:** `max_wal_senders` sets how many WAL sender processes (replication/streaming backup connections) can run at once—**default 10**, **0 disables replication**—and should be set a bit above your expected client count (e.g., **12 for ~10 clients**) to allow quick reconnects after disconnects; it’s **startup-only**, requires `wal_level >= replica`, and a standby should use **>=** the master’s value to allow queries.
