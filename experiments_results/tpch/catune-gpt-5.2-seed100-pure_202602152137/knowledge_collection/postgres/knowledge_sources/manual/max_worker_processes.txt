**SENTENCE:** `max_worker_processes` sets the maximum number of background worker processes PostgreSQL can run (default **8**) and must be configured at server startup; on a standby it must be **≥ the primary’s value** to allow queries, and if you raise it you should also review related parallel-worker limits (`max_parallel_workers`, `max_parallel_maintenance_workers`, `max_parallel_workers_per_gather`).
